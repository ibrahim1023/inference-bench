Large language model inference consists of two distinct computational phases: the prefill phase and the autoregressive decode phase. During the prefill phase, the model processes all input prompt tokens in parallel to compute the initial key-value cache states across every transformer attention layer and produce the probability distribution for the first generated token. Because prefill operates over a batch of sequence positions simultaneously, its matrix multiplications are typically compute-bound on modern accelerators once the prompt reaches a moderate length. Time to first token measures the elapsed wall-clock duration from submitting the tokenized input sequence until the first output token is materialized.

Once the first token is emitted, generation transitions into the autoregressive decode phase. Each subsequent step consumes only the most recently generated token ID, appends its key and value projections to the key-value cache, attends over all prior sequence positions, and samples the next token. Under greedy decoding with batch size one, each step reads the entire set of model weights and the growing key-value cache from memory to perform matrix-vector operations with low arithmetic intensity. Consequently, single-stream token generation rate is predominantly memory-bandwidth bound rather than compute-bound. As context length increases, reading the larger key-value cache adds incremental memory traffic per generated token. Accurate benchmarking therefore separates prefill latency from steady-state decode throughput and tracks peak device memory allocations across workloads.
